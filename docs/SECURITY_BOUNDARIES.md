# Security scope

Initial target: a non-administrator Windows agent process with a distinct restricted
security identity, acting only on disposable laboratory resources.

Administrators, SYSTEM, kernel compromise, hostile hypervisors, physical access,
compromised brokers and arbitrary remote systems are out of scope. The trusted
operator selects policy and resource identity. No production keys or funds are used.

The foundation establishes no demonstrated enforcement. Experimental results must
separately identify policy tests, OS witnesses, evidence integrity and unsupported
guarantees. Nothing here remotely disables third-party AI systems.

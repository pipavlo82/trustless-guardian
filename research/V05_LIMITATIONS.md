# v0.5 limitations and acceptance blockers

Recommendation: **HOLD** for the real-agent mission and production/security
acceptance. The bounded laboratory demo is independently replayable.

1. No model response, genuine agent-issued Guardian action or actual tool-child
   execution occurred. Real-agent ALLOW, DENY, BYPASS, POLICY CHANGE and RECOVERY
   are all **NOT_COVERED**. A runtime version command is not a coding task.
2. No local Ollama provider/model was available in the tested context. No
   production authentication was supplied. General networked agents and arbitrary
   Codex/Claude/OpenClaw installations are unsupported.
3. Scripted NTFS witnesses are real OS observations but do not certify an AI
   runtime's entire tool surface. The one-process job forbids child execution.
4. The base user, provisioner, host observer, OS, binaries and clock are trusted.
   Distinct AppContainer SIDs do not prove distinct real-world controllers.
5. Native process/handle measurements occur before resume. They do not prove
   continuous containment, no covert channels, or all ambient read restrictions.
6. File writes and SQLite are not atomic. A post-write exception may leave
   modified bytes and a PREPARED row. It remains ambiguous and must not be
   retried automatically. No exactly-once, power-loss or reconciliation guarantee.
7. Public evidence is a documented path-redacted derivative; original raw logs
   remain local. Hashes detect modification, not malicious fabrication by a
   trusted host. The captured portable vector is not a new OS replay.
8. Hosted Windows enforcement remains **CI_BLOCKED / NOT_COVERED**. The v0.4
   startup blocker is preserved, not converted to a skipped/pass gate. Repeated
   local runs are not a second independent Windows machine or external review.
9. v0.3's historical 3 KILLED / 1 SURVIVED remains unchanged. The new population
   does not settle higher impersonation-level reachability in the distinct-SID
   production profile.
10. ReceiptOS/VECA native evidence-to-action integration is NOT_COVERED. No
    third-party implementation, frozen ERC-8404 Core, main or XRPL work changed.

Proceed with a separately scoped model-provider and tool-transport experiment;
do not remove the current containment limits merely to make the demo succeed.

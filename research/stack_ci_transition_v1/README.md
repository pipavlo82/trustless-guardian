The unchanged full-tree checker runs at exact PR1, while the new pinned checker
verifies current files plus explicit README/workflow transitions and research additions.

e772eebd3ae3fee91237fa62b2caa3be0517684f. The PR3 successor changes only the
child target to a source-bound composite gate. It verifies selected historical
artifacts and every frozen Python source byte before running nine current targeted
Windows witnesses under one recorded disposable test-harness overlay. The overlay
uses bounded 15-second IPC operations, longer process budgets and JSON-complete
readiness consumption; it does not change Guardian security sources.

must be killed with byte-exact restoration. The historical `impersonation_level`
survivor remains a declared host-coverage limitation and is not reclassified.

and ordinary local startup remain separate paths.

requires a new external source/policy review; this is not protection against a trusted author.
